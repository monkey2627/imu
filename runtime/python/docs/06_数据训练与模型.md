# 数据、训练与模型

## 实时模型（SparseIMU 现行基线）

MobilePose 使用 5×3 acceleration + 5×9 orientation = feature[60]（**加速度在前**：5 个加速度各 3 维 `/30`，然后 5 个方向矩阵各 9 维；不是按传感器交错）。实时路径必须保持 Tracker 顺序（`lw rw ls rs pelvis`）、四元数 xyzw、单位、/30、Server→SMPL 基变换及前臂固定轴变换一致。

网络：Joints（60→72，双向 2 层 LSTM-256）→ Poser（72+60→96，16 个约化关节的全局 6D 旋转，再经逆运动学得到 24 个局部旋转）。训练在 SparseIMU 完成，realUse 只做推理：

| 项 | 值 |
|---|---|
| 训练数据 | AMASS paper-aligned 18 子集，60 fps，PNP 传感器顶点合成 |
| 微调 | DIP 训练被试 s_01–s_08，AMASS 回放×3，lr 5e-5，20 epoch |
| 帧率 / 窗口 | 60 fps；在线窗口 91 帧（过去 80 + 未来 10），输出窗口下标 80，滞后 10 帧 ≈ 167 ms |
| 位置 | 前臂 1961/5424（关节 18/19），小腿 1176/4662（关节 4/5），骨盆 3021（关节 0，骶骨后侧）；安装旋转为单位阵，朝向取所在骨骼的全局旋转 |
| 默认权重 | `pnp5_60a_s42_ftr3`（主基线）；`pnp5_60a_sc_ftr3` 为恒等锚定版 |

标准协议精度（DIP / TC-DIP 标定 / TC 官方标定，SIP/Ang/Pos/Mesh，三种子均值，见 SparseIMU `PROJECT_SUMMARY_20261010`）：主基线 16.41/9.25/5.31/6.46、14.05/12.91/5.91/7.05、15.79/14.57/6.50/7.71；恒等锚定 16.28/8.43/5.20/6.37、14.37/13.11/5.93/7.09、16.35/15.16/6.76/7.98。这些是**合成+DIP/TC 数据上的离线指标，不代表真机 SlimeVR 的精度**。

权重转换：训练服务器上 `python scripts/convert_sparseimu_checkpoint.py --poser <名>_poser --joints <名>_joints --name <输出名> [--anchored]`；一致性验证脚本已移到存档目录（见 `07_模型与传感器位置同步_20261019.md`）。
